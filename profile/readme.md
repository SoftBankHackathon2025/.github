# 서비스 설명
GitHub Actions와 연동된 원클릭 배포 버튼을 제공하여, 브랜치 선택 → 배포 승인 → 상태 확인까지 한 화면에서 진행할 수 있습니다.    
  - 페이지 안의 “Deploy Now” 버튼을 눌러 Personal Access Token을 입력하면, ci-cd.yml 워크플로가 즉시 실행되어 각 마이크로서비스 이미지를 빌드·스캔· 
    푸시한 뒤 EC2에 적용합니다.                                                                                                                     
  - 배포 결과와 로그 링크가 실시간으로 피드백되어, 대시보드를 벗어나지 않고 실패 원인 추적이나 재시도 트리거를 할 수 있습니다.
